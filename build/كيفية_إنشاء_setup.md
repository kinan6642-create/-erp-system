# تحويل النظام إلى setup.exe (بملف واحد فقط)

هذه الخطوة تُنفَّذ **على جهاز Windows** (وليس على لينكس)، مرة واحدة فقط.
بعدها ستحصل على ملف `setup.exe` جاهز للتوزيع أو التثبيت على أي جهاز Windows.

## المتطلبات (تُثبَّت مرة واحدة فقط على جهاز البناء فقط)
1. **Python** (نسخة 3.10 أو أحدث): https://www.python.org/downloads/
   - عند التثبيت، فعّل خيار "Add Python to PATH".
2. **Inno Setup** (لإنشاء ملف التثبيت النهائي): https://jrsoftware.org/isdl.php
   - التثبيت الافتراضي كافٍ، لا حاجة لأي إعداد إضافي.

> ملاحظة: هذان البرنامجان مطلوبان فقط على جهازك أنت (لبناء setup.exe مرة واحدة).
> المستخدم النهائي الذي يستلم setup.exe لاحقاً لا يحتاج تثبيت أي منهما.

## خطوة البناء (ملف واحد)

افتح مجلد `erp_system`، ثم شغّل بالنقر المزدوج:
```
build\make_setup.bat
```

هذا الملف الواحد يقوم تلقائياً بكل شيء:
1. يثبّت المتطلبات (Flask, waitress, PyInstaller)
2. يبني الملف التنفيذي `dist\ERP_System.exe`
3. يكتشف Inno Setup المثبّت على جهازك تلقائياً
4. يستدعيه لإنشاء ملف التثبيت النهائي

## النتيجة

بعد انتهاء السكربت بنجاح، ستجد ملف التثبيت الجاهز هنا:
```
dist_installer\setup.exe
```

هذا الملف يمكن نسخه لأي جهاز Windows وتشغيله مباشرة:
- يثبّت البرنامج في `Program Files`
- يضيف أيقونة على سطح المكتب وفي قائمة ابدأ
- عند التشغيل يفتح المتصفح تلقائياً على النظام
- قاعدة البيانات `erp.db` تُنشأ تلقائياً بجانب البرنامج عند أول تشغيل
- يتضمن برنامج إلغاء تثبيت (Uninstall) من لوحة تحكم Windows

## إذا لم يكن Inno Setup مثبّتاً بعد

سيتوقف السكربت بعد بناء الملف التنفيذي وينبّهك أن `dist\ERP_System.exe` جاهز
لكن `setup.exe` لم يُنشأ بعد. ثبّت Inno Setup من الرابط أعلاه، ثم أعد تشغيل
`build\make_setup.bat` مرة أخرى — سيكمل تلقائياً من حيث توقف وينشئ `setup.exe`.

## ملاحظات
- لتحديث النظام لاحقاً: عدّل الأكواد ثم أعد تشغيل `build\make_setup.bat` فقط.
- لتغيير أيقونة البرنامج: أضف ملف `.ico` وأضف السطر التالي داخل أمر PyInstaller
  في `build\make_setup.bat`:
  ```
  --icon "path\to\icon.ico"
  ```
