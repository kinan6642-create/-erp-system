# الحصول على setup.exe جاهز فعلياً — بدون أي جهاز Windows

لا يمكن توليد ملف .exe حقيقي (ثنائي مُصرَّف لويندوز) من بيئة Linux مباشرة —
هذا قيد تقني عام (وليس خاصاً بهذا النظام): برامج مثل PyInstaller تبني الملف
التنفيذي لنفس نظام التشغيل الذي تعمل عليه فقط.

**الحل العملي بدون أي جهاز Windows:** استخدام GitHub Actions، وهي خدمة مجانية
تُشغّل جهاز Windows حقيقي في السحابة لبضع دقائق، يبني فيها setup.exe تلقائياً
حسب الخطوات المُجهّزة مسبقاً في هذا المشروع (`.github/workflows/build-installer.yml`)،
ثم تُحمّل الملف الجاهز مباشرة من متصفحك.

لا تحتاج أي خبرة برمجية — فقط اتباع الخطوات التالية بالترتيب.

## الخطوات (حوالي 5 دقائق، مرة واحدة)

### 1. أنشئ حساب GitHub مجاني (إن لم يكن لديك)
اذهب إلى: https://github.com/signup

### 2. أنشئ مستودع (Repository) جديد
- اذهب إلى: https://github.com/new
- اكتب اسماً (مثلاً: `erp-system`)
- اختر **Private** إن أردت إبقاء الكود خاصاً
- اضغط **Create repository**

### 3. ارفع ملفات المشروع
في صفحة المستودع الجديد:
- اضغط رابط **uploading an existing file**
- افتح مجلد `erp_system` الذي استلمته مني، وحدد **كل الملفات والمجلدات** بداخله
  (بما فيها المجلد المخفي `.github` — تأكد أن مدير الملفات لديك يعرض الملفات المخفية)
- اسحبها وأفلتها في صفحة الرفع، ثم اضغط **Commit changes**

> ملاحظة: إن لم يظهر مجلد `.github` عند السحب والإفلات لأنه مخفي، أسهل حل هو
> ضغط مجلد `erp_system` بالكامل إلى ملف zip واحد ثم استخدام أداة GitHub Desktop
> (https://desktop.github.com) لرفعه دفعة واحدة، أو اطلب مني إرشادك خطوة بخطوة.

### 4. شغّل عملية البناء
- اذهب لتبويب **Actions** أعلى صفحة المستودع
- ستجد سير عمل باسم **Build Windows Installer** يبدأ تلقائياً بعد الرفع
  (إن لم يبدأ، اضغط عليه ثم **Run workflow**)
- انتظر حوالي 3-5 دقائق حتى تظهر علامة ✅ خضراء

### 5. حمّل setup.exe
- اضغط على عملية البناء المكتملة (السطر الأخضر)
- في أسفل الصفحة، تحت **Artifacts**، ستجد **ERP_System_Setup**
- اضغط عليه لتحميل ملف zip يحتوي على `setup.exe` الجاهز فعلياً

هذا هو ملف التثبيت **الحقيقي المُصرَّف** — انسخه لأي جهاز Windows وشغّله مباشرة.

## بديل: إن كان لديك أو لزميل جهاز Windows (أسرع، بدون GitHub)
شغّل `build\make_setup.bat` بنقرة مزدوجة (بعد تثبيت Python و Inno Setup)
كما هو موضح في `build/كيفية_إنشاء_setup.md` — ينتج نفس الملف مباشرة على جهازك.

## إن واجهتك أي مشكلة في خطوات GitHub
أخبرني بالخطوة التي توقفت عندها بالضبط ولقطة شاشة إن أمكن، وسأرشدك لحلها.
