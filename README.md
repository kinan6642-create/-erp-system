# نظام إدارة الأعمال المتكامل (ERP)

نظام محاسبي وإداري متكامل مبني بلغة Python (Flask) وقاعدة بيانات SQLite، يغطي:
الأقسام، السندات، المخزون، المشتريات، المبيعات، العملاء، الموردين، الصندوق والبنك،
مع محرك محاسبي تلقائي (قيود مزدوجة القيد) يُحدّث دفتر الأستاذ وميزان المراجعة
والتقارير المالية بشكل فوري مع كل عملية.

## المتطلبات
- Python 3.10 أو أحدث

## التثبيت والتشغيل

```bash
# 1) الدخول لمجلد المشروع
cd erp_system

# 2) تثبيت المكتبات المطلوبة
pip install flask

# 3) تشغيل النظام
python3 app.py
```

بعد التشغيل، افتح المتصفح على:
```
http://127.0.0.1:5000
```

## بيانات الدخول الافتراضية
- **اسم المستخدم:** admin
- **كلمة المرور:** admin123

> ينصح بتغيير كلمة المرور من شاشة "المستخدمين" بعد أول دخول.

## هيكل النظام

```

├── app.py                  # نقطة تشغيل التطبيق
├── core/                   # المحركات الأساسية

│   ├── accounting.py          # محرك القيود المحاسبية (مدين/دائن)

│   ├── schema.sql            # مخطط قاعدة البيانات الكامل (40 جدول)
│   └── seed.py                 # البيانات الافتراضية (دليل حسابات، أدوار، مستخدم admin)
├── blueprints/              # شاشات النظام (كل قسم في ملف مستقل)
│   ├── auth.py, dashboard.py, masterdata.py, sales.py, purchases.py,
│   │   inventory.py, production.py, finance.py, reports.py, settings.py
```

## الأقسام المتوفرة

| القسم | الوصف |
|---|---|
| لوحة التحكم | مؤشرات الأداء، المبيعات، الأرباح، التنبيهات |
| البيانات الأساسية | العملاء، الموردون، الأصناف، الخدمات، الوحدات، التصنيفات، الدليل المحاسبي، مراكز التكلفة |
| المبيعات | عروض أسعار، فواتير بيع، مرتجعات بيع |
| المشتريات | فواتير شراء، مرتجعات شراء |
| المخزون | أرصدة المخزون، حركة المخزون، تحويلات بين المستودعات، جرد وتسوية، تنبيهات نقص المخزون |
| الإنتاج | أوامر إنتاج (استهلاك مواد خام وإنتاج منتج نهائي بتكلفة محسوبة تلقائياً) |
| المالية | سندات قبض وصرف، مصاريف، إيرادات أخرى، تحويل صندوق/بنك، القيود اليومية، دفتر الأستاذ |
| التقارير | ميزان المراجعة، قائمة الدخل، الميزانية العمومية، التدفقات النقدية، تقارير المبيعات/المشتريات/المخزون، ديون العملاء والموردين، سجل التدقيق |
| الإعدادات | الشركة، الفروع، المستودعات، المستخدمون، الأدوار والصلاحيات، العملات، الضرائب، السنوات المالية |

## كيف يعمل المحرك المحاسبي

كل عملية تجارية (فاتورة بيع، فاتورة شراء، سند قبض، سند صرف، تسوية جرد...) تُنشئ
تلقائياً **قيداً محاسبياً متوازناً** (مجموع المدين = مجموع الدائن)، ويُحدّث في نفس اللحظة:
- المخزون (الكمية والتكلفة بطريقة المتوسط المرجح)
- رصيد العميل أو المورد
- حساب الصندوق أو البنك
- دفتر الأستاذ وميزان المراجعة والتقارير المالية

تم اختبار النظام بسيناريو كامل (شراء آجل ← بيع آجل ← سند قبض ← سند صرف) والتحقق
برمجياً من أن جميع القيود متوازنة وأن الميزانية العمومية متوازنة تماماً
(الأصول = الخصوم + حقوق الملكية + الأرباح).

## تحويل النظام إلى ملف تثبيت setup.exe لويندوز
شغّل الملف: `build\make_setup.bat` (نقرة مزدوجة واحدة على جهاز Windows) وسيُنشئ
`dist_installer\setup.exe` تلقائياً بالكامل. التفاصيل في `build/كيفية_إنشاء_setup.md`.

## ملاحظات
- قاعدة البيانات ملف واحد (`erp.db`) يمكن نسخه احتياطياً بسهولة.
- لإعادة تهيئة النظام من الصفر: أوقف التطبيق واحذف ملف `erp.db` ثم أعد التشغيل.
